# demo

**Status: CURRENT-STATE (validated, implemented) — demo assets**

Demo scripts, synthetic prompts/transcripts, and narrated walkthrough assets used to show the
validated pipeline end-to-end to a customer or field engineer.

**Synthetic data only.** Every prompt, response, and transcript in this directory must be
fabricated — never real patient data, real PII/PHI, real member IDs, real claims data, or any real
customer-identifying information (see `/.github/copilot-instructions.md` §1, §19).
